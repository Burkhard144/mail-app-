# Mail

Android-App „Mail“ – E-Mail-Programm für mehrere Konten (Gmail, GMX, WEB.DE, STRATO …).

**Installieren:** Rechts unter „Releases“ die neueste Version öffnen und die Datei `Mail-….apk` herunterladen.
Android fragt einmal, ob Chrome bzw. die Dateien-App „unbekannte Apps“ installieren darf – erlauben.

Die APK wird bei jeder Änderung automatisch von GitHub gebaut (siehe „Aktionen“).
